\# 🐰 癒しウサギの日記 – PetApp5 Web

\*\*日記を書くと、ちいさなウサギがそっと寄り添ってくれるWebアプリです。\*\*



\---



\## 🌟 このアプリについて



「癒しウサギの日記」は、

あなたが書いた \*\*日記の内容に応じて、ウサギが短い言葉やしぐさで反応してくれる\*\*

シンプルでやさしい “寄り添い型” の日記アプリです。



日記の内容は、

\*\*特定のキーワードをもとにした軽量ルールベースAI\*\* によって

感情（Emotion）とニーズ（Need）を判定し、

それに応じた行動（R01〜R19）を選びます。



\---



\# 🖥 画面の構成



\### ① ペット名の設定（画面上部）

ウサギに名前をつけてあげてください。



```

\\\\\\\[ ウサギの名前 ] \\\\\\\[ 名前を設定 ]

```



設定すると、ウサギはその名前で呼びかけられるのを待ちます。



\---



\### ② 話しかける（音声認識）

名前を設定すると、ウサギはあなたの声を聞き始めます。



話した内容は画面に表示されます：



```

話しかけてね

────────────────────

レオ おはよう

────────────────────

```



\---



\### ③ ウサギの反応（中央）

ウサギの画像と吹き出しが表示されます。



```

\\\\\\\[ウサギ画像]

「もぐもぐ。」

```



あなたの言葉や日記に応じて、短い言葉で返事をします。



\---



\### ④ 日記を書く（画面下部）

今日の気持ちをウサギに聞かせることができます。



```

今日は疲れた。早く寝たい。

\\\\\\\[ ウサギに聞かせる ]

```

\# 🎤 ウサギに話しかける方法（Direct Talk）



現在のバージョンでは、

\*\*特定の言葉にのみ反応します。\*\*



例：名前を「レオ」にした場合



| 話しかける言葉 | ウサギの反応 |

|----------------|--------------|

| レオ、おはよう | あいさつ |

| レオ、元気？ | 体調 |

| レオ、かわいい | 喜び |

| レオ、おやすみ | 休息 |

| レオ、ごはん | 食べ物（R19 / ぽりぽり） |

| レオ、牧草 | 食べ物（R17 / もぐもぐ） |

| レオ、チモシー | 食べ物（R17 / もぐもぐ） |

| レオ、水 | 飲み物（R18 / ごくごく） |

| レオ、お水 | 飲み物（R18 / ごくごく） |

| レオ、お腹すいた | 食べ物（R03） |



※ その他の言葉には反応しない場合があります（今後拡張予定）

\# 🐇 ウサギの行動（例）



| 感情×Need | 行動例 |

|-----------|--------|

| fatigue\_apathy × quiet\_rest | R15（そばで眠る） |

| sadness × companionship | R01（寄り添う） |

| anxiety\_fear × reassurance | R03（安心させる） |

| loneliness × companionship | R01 / R06 |

| joy × share\_joy | R14（喜びを共有） |

| anger × relaxation | R07 / R05 |

| fallback | R04（静かに寄り添う） |

\# 🌙 Idleモード（自動で話しかける）



何もしていなくても、ウサギはときどき短い言葉を話します。

時間帯によって行動が変わります。



| 時間帯 | 行動 |

|--------|------|

| 06–10 | R17 / R18 / R19 |

| 10–16 | R08 |

| 16–20 | R17 / R18 / R19 |

| 20–06 | R15 |

\# 🛠 動作環境



\- 最新ブラウザ（Chrome / Edge / Safari）

\- マイクが使える環境

\- \*\*GitHub PagesなどのWebサーバー環境で動作します\*\*



※ `file://` で直接開くと、ブラウザのセキュリティ制限により

　JSON読み込みが動作しない場合があります。



\---



\# 💬 困ったときは



\- 音声認識が動かない → マイクの許可を確認

\- ウサギが反応しない → 名前を設定してから話しかけてください

\- 日記に反応しない → キーワードが含まれているか確認してください
