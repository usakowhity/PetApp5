\# 癒しウサギの日記 🐇  

PetApp5-Web v3.2.7



\---



\## 🌸 概要

\*\*癒しウサギの日記\*\* は、あなたの気持ちをウサギに話しかけたり、日記として書き留めたりできるウェブアプリです。  

ウサギがあなたの言葉に反応し、時間帯に応じて自然な行動を見せてくれます。  

音声認識・感情解析・行動選択が連携した、PetApp シリーズ第5作です。



\---



\## 🧩 主な機能



| 機能 | 説明 |

|------|------|

| 🎙️ \*\*Direct Talk\*\* | 音声認識でウサギに話しかけると、言葉に応じた反応を返します。 |

| 📔 \*\*Diary\*\* | 今日の気持ちを入力すると、感情とニーズを解析してウサギが応答します。 |

| 🌙 \*\*Idle Layer\*\* | 時間帯に応じてウサギが自動的に行動します（20秒ごとに更新）。 |

| 🐰 \*\*UI設定\*\* | ウサギの名前を自由に設定できます。 |

| ☁️ \*\*GitHub Pages公開\*\* | \[https://usakowhity.github.io/PetApp5/](https://usakowhity.github.io/PetApp5/) で公開中。 |

\## 📔 Diary（感情解析）



日記入力欄に自由に文章を書くと、  

テキストから感情とニーズを自動検出してウサギが応答します。



| 感情 | ニーズ | 例文 |

|------|---------|------|

| 疲れ | quiet\_rest | 「今日は疲れた…」 |

| 悲しみ | companionship | 「つらいことがあった」 |

| 不安 | reassurance | 「心配で眠れない」 |

| 寂しさ | companionship | 「誰かに会いたい」 |

| 喜び | share\_joy | 「嬉しいことがあった！」 |

| 怒り | relaxation | 「イライラする」 |

| その他 | companionship | 「なんとなく」 |



\---



\## 🌙 Idle Layer（自動行動）



時間帯に応じてウサギが自動的に行動します。  

20秒ごとに短文（`short\_phrases`）をランダム表示。



| 時間帯 | 行動候補 | 説明 |

|--------|-----------|------|

| 朝（6〜10時） | R17, R18, R19 | 食事・水飲み |

| 昼（10〜16時） | R08 | 休憩・ねんね |

| 夕方（16〜20時） | R17, R18, R19 | 食事・活動 |

| 夜（20〜翌6時） | R15 | 休息・おやすみ |

\## 🧠 技術構成



| 要素 | 内容 |

|------|------|

| 言語 | JavaScript（ES6） |

| 音声認識 | Web Speech API |

| データ構造 | `rabbit\_actions.json` に行動定義を格納 |

| 表示制御 | `uiRenderer.js` による描画管理 |

| 行動選択 | `rabbitActionSelector.js` による emotion × need マッピング |

| 保存 | localStorage に日記データを保存（PWA対応予定） |
